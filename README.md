# Gatherer

An LLM-free Minecraft bot that gets you the items you ask for: it mines,
crafts, smelts, farms, breeds, hunts and brews, fights, and learns from
experience. Built on Mineflayer, for Minecraft 26.3.

- [`gatherer/`](gatherer/README.md): the bot (Node.js).
- [`gatherer-mod/`](gatherer-mod/README.md): Fabric mod for 26.3 that shows the
  bot dashboard in game (press **J**).

This repo started as a fork of [Voyager](https://github.com/MineDojo/Voyager)
(MIT License); the original LLM-driven Voyager agent has been removed.
